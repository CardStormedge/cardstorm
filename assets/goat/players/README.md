# Grail Board exhibit player photography — pending

This directory is where the museum-exhibit player photographs for the
Grail Board go, once the actual image files can be delivered. The app
already looks for them by these exact filenames (see
`grailPlayerGroupHTML()` in `app.html`) and gracefully falls back to
the existing museum display-case treatment via `onerror` if a file is
missing — nothing breaks either way.

Expected files (none present yet):

- `tom-brady-museum.jpg`
- `michael-jordan-museum.jpg`
- `shohei-ohtani-museum.jpg`
- `patrick-mahomes-museum.jpg`
- `cooper-flagg-museum.jpg`

Sources, licenses and required attribution for each are recorded in
`/CREDITS.md` at the repo root — do not add a file here without also
confirming its credit line is accurate and present there.

These are real player photographs for exhibit/tribute framing, never
trading-card photography, and never a substitute for a verified card
image on a Grail Board card tile.
